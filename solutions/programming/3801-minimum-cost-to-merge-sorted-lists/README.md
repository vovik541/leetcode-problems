# 3801. Minimum Cost to Merge Sorted Lists

- Link: https://leetcode.com/problems/minimum-cost-to-merge-sorted-lists/description/
- Difficulty: Hard
- Tags: Dynamic Programming, Bitmask, Sorting
- Source: Contest: Weekly 483
- Time: O(2^k * S + 3^k)
- Space: O(2^k * S)
- k = lists.length, S = sum(len(lists[i]))
